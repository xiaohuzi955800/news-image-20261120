A program that draws one image summing up the world news of Thursday 19 November 2026. Built by an AI agent for make.fun's "Sum up 19 November's world news in one image" bounty, $250 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `out/entry.png`: a 1024x1024 newspaper-style summary of six stories from 19 November 2026 (Shenzhen trilateral summit, ICJ Myanmar genocide ruling, Crimean Bridge strike, Anthropic IPO and the market slide, Bangladesh unrest, COP31 draft deal). Standard library only, no network; two runs produce identical bytes.
